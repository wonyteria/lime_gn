# 라임하우스 입실 문의 전화 링크 접근성 개선

- 명세 번호: `feature_46fc6d35ec5a4ea68934`
- 리비전: 2
- 기준 소스: `wonyteria/lime_gn`의 `main` 커밋 `12ef73141024337cffa2d9d0337c2449e75007ac`

## 목적

보조기술 사용자가 「오는 길과 입실 문의」 구역의 전화 링크 목적과 전화번호를 명확히 인식하도록 접근성 이름을 제공한다.

## 변경 명세

`index.html`의 `#visit` 구역에 있는 버튼형 전화 링크에 다음 `aria-label` 속성 하나만 추가한다.

```html
<a class="btn dark" href="tel:025640143" aria-label="라임하우스 입실 문의 전화 02-564-0143">02-564-0143</a>
```

표시 문구 `02-564-0143`과 링크 목적지 `tel:025640143`은 유지한다. 같은 번호를 사용하는 상단 문의 메뉴의 전화 링크는 변경하지 않는다. CSS, 화면 배치·모양, 다른 링크·문구·스크립트·이미지는 변경하지 않는다.

## 사용자 흐름 및 예외

사용자가 「오는 길과 입실 문의」 구역으로 이동하면 화면에는 기존 전화번호가 표시되고, 스크린 리더는 링크를 `라임하우스 입실 문의 전화 02-564-0143`으로 인식한다. 링크 실행 시 기존 전화 목적지를 호출한다. 전화 연결 또는 `aria-label`을 지원하지 않는 환경의 기존 동작은 변경하지 않는다.

인증이나 별도 권한은 필요하지 않으며 신규 데이터 수집·저장·전송은 없다.

## 구현 결과

- `#visit`의 대상 링크에 지정된 `aria-label`을 추가했다.
- 대상의 표시 문구와 `tel:` 목적지를 유지했다.
- 상단 문의 메뉴 전화 링크 및 CSS를 변경하지 않았다.
- 운영 브랜치 병합, 원격 푸시, 초안 PR 생성, 배포 및 DNS 변경은 수행하지 않았다.

## 전달 및 배포 전 점검

- 작업 브랜치에서 제품 코드 diff가 대상 속성 추가 한 건인지 검토한다.
- 정적 검사로 대상 `aria-label`, 표시 문구와 `href`를 확인한다.
- 상단 문의 메뉴의 전화 링크가 수정되지 않았는지 확인한다.
- 화면과 스타일에 차이가 없는지 브라우저 검토 단계에서 확인한다.
- 검사 통과 후 감독 절차에서 작업 브랜치 푸시와 초안 PR을 준비한다.
- 운영 `main` 병합과 GitHub Pages 배포는 수행하지 않는다.
